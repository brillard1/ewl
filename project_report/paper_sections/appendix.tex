\subsection{Training Step (Pseudocode)}

\begin{algorithm}[h]
\caption{EWL Training Step}
\label{alg:ewl}
\begin{algorithmic}[1]
\Require Batch $\{(x_i, y_i)\}$, EMA state $\{\mu_i\}$,
         lagged proxy $g_{\text{prev}}$, temperature $\tau$, warmup $K$
\State Compute per-sample losses $\{\ell_i\}$
\If{step $\le K$} \textbf{return} uniform weights $w_i = 1/B$ \EndIf
\State $\mu_i^{\text{prev}} \gets \mu_i$
\State $\mu_i \gets \alpha\,\mu_i + (1{-}\alpha)\,\ell_i$
\State $s_i \gets \dfrac{\mu_i^{\text{prev}} - \ell_i}{|\mu_i^{\text{prev}}|+\varepsilon}
       \cdot\,\mu_i \cdot\,g_{\text{prev}}$
\State $w_i \gets \operatorname{softmax}(s / \tau)$
\State Backprop $\mathcal{L}_{\text{EWL}} = B\sum_i w_i\,\ell_i$
\State $g_{\text{prev}} \gets \tfrac{1}{|\Lambda|}
       \sum_{\theta \in \Lambda}\|\nabla_\theta\|_F$
\end{algorithmic}
\end{algorithm}

\subsection{Theoretical Grounding}

\paragraph{Gradient variance reduction.}
Optimal importance weights for gradient estimation are proportional to the
per-sample gradient norm
$\|\nabla_\theta \ell_i\|$~\cite{katharopoulos2018notall}.
Computing these exactly requires $O(B)$ backward passes per step, which is
infeasible.
EWL's velocity $(\mu_i^{(t-1)} - \ell_i^{(t)})/|\mu_i^{(t-1)}|$ is a cheap
temporally smoothed proxy: a sustained loss decline implies a large gradient
aligned with the current update direction.
Upweighting these samples reduces the variance of the gradient estimator, and
the argument holds for any first-order optimiser.

\paragraph{LoRA subspace alignment.}
LoRA constrains weight updates to a rank-$r$ subspace $\Delta W = BA$.
A mislabelled or out-of-distribution sample's gradient often lies largely
\emph{outside} this subspace; the rank-$r$ constraint prevents the model from
reconciling it, so its loss stagnates.
EWL identifies this via stagnant loss velocity --- the observable signature of
subspace misalignment --- without requiring knowledge of the adapter geometry.
As $r$ increases and more gradient directions become reachable, fewer samples
are truly irreconcilable and EWL's marginal advantage over SFT should diminish;
the rank sweep in Appendix~\ref{app:rank} is consistent with this.

\section{Implementation Details}
\label{app:implementation}

\subsection{Model and LoRA Configuration}

We use ViT-Small/16~\cite{dosovitskiy2021image} loaded from
\texttt{timm}~\cite{wightman2021timm} with ImageNet-21k pretraining.
The model has 21.7M total parameters across 12 transformer blocks
(6 heads, head dim 64, MLP hidden 1536).
LoRA adapters are applied to $W_Q,W_K,W_V,W_O$ in every attention block
($12\times 4 = 48$ adapter pairs).
The classification head is fully fine-tuned (no LoRA).
Default rank $r{=}4$ gives 307K trainable parameters (1.41\% of total).

\subsection{Data Augmentation and Training}

Training augmentation: \texttt{RandomResizedCrop(224, scale=(0.6, 1.0))},
horizontal flip ($p{=}0.5$), \texttt{ColorJitter(0.4, 0.4, 0.4, 0.1)} with
$p{=}0.8$, then ImageNet normalisation.
Validation: \texttt{Resize(256)} $\to$ \texttt{CenterCrop(224)}.

\subsection{Hardware}

All experiments were run on a single NVIDIA GPU with 10\,GB VRAM.
Peak GPU memory usage was 9.46\,GB for both SFT and EWL.
EWL per-sample state (EMA values, previous signal) is maintained on CPU as a
Python dictionary, totalling 16.3\,KB per run regardless of dataset size.

\subsection{Label Noise and Class Imbalance Protocol}

Uniform random label noise is injected into the training set only; validation
and test sets remain clean.
For noise rate $\rho$, a random $\lfloor \rho N_{\text{train}} \rfloor$
examples have their labels replaced with a uniformly sampled incorrect class.
The same noisy assignment is used across all three seeds at a given noise
level.
Class imbalance is introduced by subsampling majority classes while keeping
all examples from the minority class; IF$=k$ means the most frequent class has
$k$ times as many samples as the least frequent.

  }
  \label{fig:proxy_delta}

On Aircraft, the $-6.76\%$ gap is not a final-accuracy plateau difference but
a training instability.
Without the proxy, the raw progress signal applies aggressive reweighting from
step 1, before the EMA has accumulated meaningful history.
Aircraft's 100 visually similar classes have densely packed decision
boundaries; indiscriminate early reweighting amplifies unstable gradient
directions and the model cannot recover.
On CUB-200 and Dogs classes are more separable, so the same instability causes
smaller but still consistently negative drops ($-0.18\%$ and $-0.54\%$).
The proxy prevents this by keeping effective weights uniform
($g \approx 0$) during early training and sharpening them only as the adapter
begins meaningful adaptation.

does not substitute for explicit re-balancing.
The slight positive trend at high IF is within standard deviation and should
not be over-interpreted.

\section{Extended Discussion and Limitations}
\label{app:discussion}

\subsection{Cost-Benefit Analysis}

\paragraph{When the cost is justified.}
On Aircraft with 20--40\% noise, EWL recovers $+5.9$--$6.8\%$ over SFT.
A typical Aircraft run (50 epochs, 3,334 samples) takes $\sim$15 minutes for
SFT and $\sim$90 minutes for EWL per seed.
The per-percentage-point wall-clock cost is $\sim$12 minutes --- reasonable
when the dataset has a wide adaptation frontier and significant label noise.

\paragraph{When the cost is not justified.}
On CUB-200 and Dogs under noise, EWL is strictly worse than SFT.
On clean data across all three datasets, EWL gives $\leq\!+0.16\%$ --- within
standard deviation --- making the overhead unjustifiable unless label noise
is a known concern.

\subsection{Limitations}

\paragraph{Marginal clean-data gains.}
On noise-free data, EWL matches SFT within standard deviation across all three
benchmarks ($\Delta \leq +0.16\%$).
The adaptation frontier is not a sufficient proxy for ``difficult but
learnable'' examples when labels are clean, and clean-data performance should
not be cited as a benefit of EWL.

\paragraph{Frequency-blindness.}
EWL's progress signal is purely velocity-based and has no notion of class
frequency.
A rare-class sample that never improves --- because it is genuinely hard, not
noisy --- receives the same near-zero weight as a mislabelled sample.
Combining progress-based weighting with class-aware reweighting is an open
direction.

\paragraph{Single-pass and streaming incompatibility.}
EWL's EMA requires that each training sample is visited multiple times across
epochs.
Single-pass fine-tuning or streaming settings break this assumption --- the
EMA never converges, the signal is unreliable, and the warmup never terminates
meaningfully.
A reservoir or sliding-window approximation is left as future work.

\paragraph{Architecture and task scope.}
All experiments use ViT-Small/16 on fine-grained visual classification.
Whether the adaptation frontier hypothesis generalises to language models,
generation, regression, or other PEFT methods beyond LoRA is not established
here.
